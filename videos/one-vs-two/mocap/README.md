# Motion capture data
`dm/` holds DeepMimic reference motions (github.com/xbpeng/DeepMimic, MIT-licensed repo; motions
derived from the CMU Graphics Lab Motion Capture Database and SFU Motion Capture Database).
Used by `../src2/mocap.py` to drive the stick fighters.
`cmu/` holds CMU Graphics Lab Motion Capture Database trials (mocap.cs.cmu.edu, free to use):
boxing/sparring takes 13_17, 13_18, 14_01, 14_02, 15_12 (continuous footwork base layer) plus
martial-arts/kick/block trials from subjects 135, 143, 144.
