# The parking brake TRUTH

9:16 pixel explainer, 1080x1920, 60 fps, 17.2 s. Source in `src/`; render with
`python render.py video voiceover.mp3 <out.mp4>` from `src/`.

Description: On many older cars with rear drum brakes or a cable handbrake, a parking
brake that's never used can rust and stick. Pull it on now and then on a flat road
and check it holds. Electric parking brakes adjust themselves.
